# NexicWeb Backend

Node.js + Express + Supabase backend for NexicWeb

## Setup

1. Install dependencies:
```bash
npm install
```

2. Create `.env` file (copy from `.env.example`):
```bash
copy .env.example .env
```

3. Add your Supabase credentials in `.env`

4. Run the server:
```bash
npm run dev
```

Server runs on: http://localhost:5000
